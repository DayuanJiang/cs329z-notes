一句话的结论

大语言模型（LLM）是一个根据前面的 token 预测下一个 token 的概率模型。它的结构、训练方式和推理方式各自带来一些限制，搭 agent 时怎样规定输出格式、怎样安排上下文，都是在这些限制里做选择。

下面的表把「模型的一个事实」和「它对搭 agent 的影响」一一对上。

八个问题

这一讲分八个部分，每个部分回答一个问题。下表先给出每个问题的答案和一条依据，推导和出处在各部分的页面里。表里有些词到对应的部分才展开，表后面先各给一句解释。

表里到各部分才展开的词，大致按出现的顺序各给一句解释。

  • greedy、top-k、top-p 和束搜索是从概率分布里挑下一个 token 的四种办法。greedy 每一步都选概率最高的 token。top-k 只在概率最高的 k 个 token 里随机抽。top-p 把 token 按概率从高到低排好，从头往后加，累计概率达到 p 就停，只在这些 token 里随机抽，所以候选的个数每一步都可能不同。束搜索同时保留几条候选的序列，最后选整条序列得分最高的。
  • 位置向量是加到每个 token 的向量上、表示它排在第几个的一组数。前馈网络是对每个 token 的向量单独做一次变换的那一层。
  • query、key、value 是注意力层为每个 token 算出的三个向量：query 表示它在找什么，key 表示它有什么，value 是别的 token 看它时它交出去的内容。
  • ConvS2S 是一个用卷积网络做翻译的模型。集成模型指把几个分别训练的模型的预测合起来用。
  • 预训练、中期训练和后训练是训练的先后三个阶段。预训练让模型在海量文字上学预测下一个 token，后训练用专门挑选的数据教模型按人希望的方式回答，中期训练夹在两者之间。
  • 交叉熵损失是训练时衡量模型离目标有多远的一个数：模型给真实的下一个 token 的概率越高，它越低。
  • 配比是各种来源的数据在训练数据里各占多少。
  • 指令微调是用很多条「指令加上理想的回答」接着训练模型。
  • DCLM 是一个公开的预训练数据集和基准测试。SWE-smith 是一种自动造训练任务的办法。SWE-bench Verified 和 SWE-bench Lite 是修真实代码仓库里 bug 的基准测试。
  • 内存带宽是数据从内存送到计算单元的速度。
  • KV cache 是推理时保存下来重复使用的中间结果。
  • 约束解码是在生成的每一步只允许合法的 token。SGLang 是实现这种做法的一个库。吞吐量是单位时间里处理的请求量。
  • 分类头是接在模型上的一个很小的分类器，把模型算出的向量变成每个类别的分数。
  • 状态指模型当前面对的情况，比如一幅游戏画面或一段文字。候选动作是这一步可以选的几个选项，比如一份工具清单里的各个工具。
  • OOLONG 是一个专门测长上下文的基准测试。

容易想当然的八件事

表里提到的模型、基准测试、文章和几个术语在各部分里都有交代，表后面先各给一句解释。每一件的出处和细节在最后一列指向的页面里。

表里出现的名字和术语，按出现的顺序各给一句解释。

  • softmax 是把一组分数变成加起来等于 1 的概率的函数。
  • RWKV 和 Mamba 是两个不用标准注意力的模型。Mamba 用的状态空间模型是另一类结构：它用一个固定大小的状态记住读过的内容，结构里没有注意力。RULER 是一个测长上下文能力的基准测试。
  • Marin 是一个把训练全过程公开出来的语言模型项目。数据桶是它按主题和质量给文档分的组，一个桶的占比是它在训练数据里占的比例。冷却阶段（cooldown）是预训练之后、后训练之前的一段训练，也叫中期训练。
  • Inkling 和 Kimi K3 是两个推理强度可以调的模型。
  • KV cache 是推理时保存下来重复使用的中间结果。位置向量是加到每个 token 的向量上、表示它排在第几个的一组数。
  • OOLONG 是一个专门测长上下文的基准测试。
  • HarnessTax 是 Arena 团队比较三种运行框架的一篇文章。运行框架（harness）是包在模型外面、给它工具并管理多轮对话的程序。Pi 是其中很精简的一种，只给模型四个工具。误差线是图上每根柱子带的一段线，表示结果可能波动的范围。
