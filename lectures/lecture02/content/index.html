先看结论

大语言模型（LLM）是一个根据前面的 token 预测下一个 token 的概率模型。它的结构、训练方式和推理方式各自带来一些限制，搭 agent 时怎样规定输出格式、怎样安排上下文，都是在这些限制里做选择。

下面的表把「模型的一个事实」和「它对搭 agent 的影响」一一对上。这一讲分八个部分，每个部分一页，表的最后一列写的是这件事在第几部分讲。表里有三个词，先各给一句解释。

  • 词表是所有可能的 token 组成的固定集合。
  • 注意力是模型里让每个 token 用到前面各个 token 的信息的那一层计算。这一讲讲到它的两种算法，标准注意力和线性注意力，两者的差别见表的第二行。
  • 运行环境指一套装好了代码和所需软件、agent 可以在里面实际动手操作的系统。

八个问题

这一讲分八个部分，每个部分回答一个问题。下表先给出每个问题的答案，以及支持它的依据或例子，推导和出处在各部分的页面里。表里有些词到对应的部分才展开，表后面先各给一句解释。

表里到各部分才展开的词，大致按出现的顺序各给一句解释。

  • greedy、top-k、top-p 和束搜索是从概率分布里挑下一个 token 的四种办法，这类办法叫解码策略。greedy 每一步都选概率最高的 token。top-k 只在概率最高的 k 个 token 里随机抽。top-p 把 token 按概率从高到低排好，从头往后加，累计概率达到 p 就停，只在这些 token 里随机抽，所以候选的个数每一步都可能不同。束搜索同时保留几条候选的序列，最后选整条序列得分最高的。
  • Transformer 是 2017 年提出的一种模型结构，现在的大语言模型大多用它。位置向量是加到每个 token 的向量上、表示它排在第几个的一组数。前馈网络是对每个 token 的向量单独做一次变换的那一层。
  • 注意力层是模型里让每个 token 用到前面各个 token 的信息的那一层计算。query、key、value 是注意力层为每个 token 算出的三个向量：query 表示这个 token 在找什么，key 表示它有什么，value 是别的 token 看它时它交出去的内容。
  • ConvS2S 是一个用卷积网络做翻译的模型，卷积网络是另一类神经网络结构。集成模型指把几个分别训练的模型的预测合起来用。
  • 线性注意力那一行里的状态，指模型内部保存的一块大小固定的数据，前面读过的内容都汇总在里面。DeltaNet 是线性注意力的一个改进版，Transformer++ 是全部用标准注意力的参照模型。Kimi K3 是月之暗面（Moonshot AI）的 Kimi 团队在 2026 年公开权重的一个大模型，公开权重指训练好的模型参数公开发布、可以下载。
  • 预训练、中期训练和后训练是训练的先后三个阶段。预训练让模型在海量文字上学预测下一个 token，后训练用专门挑选的数据教模型按人希望的方式回答，中期训练夹在两者之间。
  • 交叉熵损失是训练时衡量模型离目标有多远的一个数：模型给真实的下一个 token 的概率越高，它越低。
  • 配比是各种来源的数据在训练数据里各占多少。
  • 微调是用自己的数据接着训练模型。指令微调是用很多条「指令加上理想的回答」接着训练模型。
  • DCLM 是一个公开的预训练数据集和基准测试。SWE-smith 是一种自动造训练任务的办法。SWE-bench Verified 和 SWE-bench Lite 是修真实代码仓库里 bug 的基准测试。
  • 内存带宽是数据从内存送到计算单元的速度。
  • KV cache 是推理时保存下来重复使用的中间结果。
  • 推测解码这个名字里的「解码」就是 decode，指一个一个地生成 token。
  • 思考过程是模型在给出答案之前写出来的一步步的思考。思考强度是让模型想多久的设置。推理模型这个名字里的「推理」指思考，和「推理时」里的推理是两回事。
  • 约束解码是在生成的每一步只允许合法的 token。SGLang 是实现这种做法的一个库。吞吐量是单位时间里处理的请求量。
  • 分类头是接在模型上的一个很小的分类器，把模型算出的向量变成每个类别的分数。
  • 第七行里的状态和线性注意力那一行里的状态是两个意思。这里它指模型当前面对的情况，比如一幅游戏画面或一段文字。候选动作是这一步可以选的几个选项，比如一份工具清单里的各个工具。
  • OOLONG 是一个专门测长上下文的基准测试，GPT-5 是 OpenAI 的模型。

按部分阅读

第一部分语言模型是什么，怎么从它生成文字

三层技术的划分（造模型、让模型适应场景、在模型之上搭应用这三层）；算概率的公式；生成式和判别式（机器学习模型的两类）；greedy、top-k、top-p；temperature；束搜索。

 第二部分Transformer 怎么算出下一个 token 的概率

之前的几代语言模型；词向量（每个 token 对应的向量）和位置向量；注意力层的八个小步；多头，也就是把注意力并排做好几遍；整个模型；和循环神经网络（一个 token 一个 token 地读、每读一个就更新一次内部状态的模型）的比较。

 第三部分线性注意力、混合结构和上下文长度

换一个相乘的顺序；不断更新的状态；快在哪里，弱在哪里；上下文长度的上限从哪来；混合结构；Kimi K3。

 第四部分一个模型是怎么训练出来的

交叉熵损失；从网页到训练集；数据配比；中期训练；后训练的三类做法：指令微调、学人的偏好、能自动判对错的奖励；为 agent 造任务。

 第五部分推理的时间花在哪里

GPU 和屋顶线模型（一张用来判断速度受算力限制还是受内存带宽限制的图）；prefill 和 decode；KV cache；两个指标和价格；推测解码。

 第六部分推理时多花算力，换更好的答案

chain of thought（先写思考过程再回答）；推理模型（reasoning model，先写出思考过程再回答的模型）；思考强度的档位和它的训练办法；同一道题做很多遍再挑；自洽性（让多次的答案投票）。

 第七部分让模型的输出能被程序解析

复合 AI 系统，也就是由几个部件配合工作的 AI 系统；约束解码；DSPy 这个库的 signature（一份输入和输出各有哪些字段的声明）；分类头；System One 模型（选项可以随时更换的分类器）；调用工具。

 第八部分上下文工程：往上下文里放什么，怎么放

上下文里有什么；context rot（上下文越长，模型越用不好其中信息）；四条做法；compaction（上下文满了之后把历史总结成摘要）和一起事故；递归语言模型（把长输入放进代码环境，让模型写代码去处理）；整讲的小结。

表里出现的名字和术语，按出现的顺序各给一句解释。

  • softmax 是把一组分数变成加起来等于 1 的概率的函数。归一化是把一组数按比例调整，让它们加起来等于 1。
  • query、key、value 是注意力层为每个 token 算出的三个向量。标准注意力先拿 query 和 key 相乘，线性注意力改成先拿 key 和 value 相乘。
  • RWKV 和 Mamba 是两个不用标准注意力的模型。Llama2-7B 是 Meta 的模型 Llama 2 的 70 亿参数版本，用的是标准注意力。Mamba 用的状态空间模型是另一类结构：它用一个固定大小的状态记住读过的内容，结构里没有注意力。RULER 是一个测长上下文能力的基准测试。
  • Marin 是一个把训练全过程公开出来的语言模型项目。数据桶是它按主题和质量给文档分的组，一个桶的占比是它在训练数据里占的比例。相关系数是衡量两个量是不是一起变大变小的一个数。冷却阶段（cooldown）是预训练之后、后训练之前的一段训练，也叫中期训练。
  • Inkling 是 Thinking Machines 的模型，Kimi K3 是月之暗面的模型，两个模型的思考强度都可以调，思考强度是让模型想多久的设置。两个模型都在强化学习里训练这种能力，强化学习是让模型自己去做任务、再按结果得到的奖励来更新模型的训练办法。
  • 任务奖励是任务本身做得怎样得到的奖励，token 惩罚是按生成的 token 数成比例扣掉的奖励，预算是一道题允许用的 token 数。
  • Raschka 的文章指 Sebastian Raschka 2026 年 7 月的文章《Controlling reasoning effort in LLMs》。
  • KV cache 是推理时保存下来重复使用的中间结果。位置向量是加到每个 token 的向量上、表示它排在第几个的一组数。
  • OOLONG 是一个专门测长上下文的基准测试，Gemini 2.5 Pro 是 Google 的模型。
  • HarnessTax 是 Arena 团队比较三种运行框架的一篇文章。运行框架（harness）是包在模型外面、给它工具并管理多轮对话的程序。Pi 是其中很精简的一种，只给模型四个工具。误差线是图上每根柱子带的一段线，表示结果可能波动的范围。
