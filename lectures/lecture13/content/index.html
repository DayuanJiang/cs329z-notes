一句话的结论

一个基准测试的分数，是两样东西合起来的结果：题目本身，和这个分数是怎么跑出来的。讲义把前一样叫任务定义，后一样叫评估协议。题目出得不好，分数说明不了能力。题目出得好，跑分的方式不一致，分数之间也没法比。

这里的 agent，指能自己调用工具、分很多步去完成一个任务的语言模型系统。这一讲的前一半教你把一个 agent 基准测试拆开来看，后一半分别说这两样要满足什么：好的基准测试有七条性质，可信的分数有四条要求。

整条线：五个问题

讲义最后的结论是：没有哪一个评测能说明一切。要判断一个模型或 agent 的能力，得同时看很多个基准测试。
