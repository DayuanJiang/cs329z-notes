一句话的结论

软件越来越多地由模型和 agent 生成之后，想确认它实际会做什么、做得对不对，最后的依据从代码变成了评估。评估本身是由一个个任务组成的软件，要像软件一样写、测试、发版本、持续修。

这里的 agent，指能自己调用工具、分很多步去完成一个任务的语言模型系统。

这一讲用的例子是 Terminal-Bench 和 Harbor。Terminal-Bench 是一个基准测试（benchmark，一组题目加一个打分的办法），题目是让 agent 在命令行环境里完成真实的技术工作。Harbor 是这个团队把做基准测试的经验整理成的一套工具。

下表把一个评估任务从写到修的四个环节，和软件工程里对应的做法放在一起。
