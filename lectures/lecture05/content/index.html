先看结论

有了框架，搭出一个能跑的 agent 只要一两行代码。把它当工程来做，要的是另外几样东西：数据，评估，可靠的运行，和看得见的运行记录。这一讲的框架和工具在这几样上各提供了一套抽象，用的时候要知道抽象底下实际发生了什么。

这里的 agent，指能自己调用工具、分很多步去完成一个任务的语言模型系统。

「框架」（framework）指 DSPy、LangGraph 这类写程序时调用的库。和框架并提的工具，指管可靠运行的平台 Temporal，和查看运行记录的 MLflow、LangSmith、Langfuse。框架和页首说的「运行框架」（harness）是两个东西，这一讲两样都会讲到。

抽象（abstraction）指框架把底层的细节包起来之后，留给写程序的人用的那几个概念。

下表把「搭出一个能跑的 agent」和「把它当工程来做」放在一起比较。这一讲分七个部分，表的最后一行写的是这两栏各在哪几个部分讲。

表里有六个词先说明一下。带标准答案的数据指每条输入都配有正确结果的数据。度量（metric）是一个给程序的输出打分的函数。可观测性（observability）就是上面说的「看得见的运行记录」：能从外面看到系统内部每一步发生了什么。dspy.ReAct 是 DSPy 里现成的一个 module（模块，DSPy 里决定怎样调用模型的部件），把一组工具交给它，就得到一个由模型自己决定调用哪些工具的 agent。LangChain 是 LangChain 公司的一个 Python 库，LangGraph 也出自这家公司。LangChain 里的 create_agent 函数建出一个用 LangGraph 搭成的 agent。

这一讲分七个部分，每个部分回答一个问题。下表每一行给出问题、答案和一个依据或例子。

表里有六个名字先说明一下。控制流指程序里「接下来执行哪一步」的决定。PyTorch 是一个用来训练神经网络的 Python 框架。signature 是 DSPy 里对模型输入和输出的声明。基准测试（benchmark）是一组题目加一个打分的办法。Terminal-Bench 2.0 是一个基准测试，题目是让 agent 在命令行环境里完成任务。HarnessTax 是 Pan 等六人 2026 年发表在 arena.ai 博客上的一篇文章，它测量换一个运行框架对成功率和花费有多大影响。

容易想当然的六件事

这张表适合读完各部分之后再看，表里的说法和例子在各部分里都有交代。下面六件事，左列的说法都比实际情况简单。每一件在对应的页面里有出处和细节。其中第一、二、四件就是各部分里用橙色的框标出的那三处，另外三件写在各部分的正文、表格或蓝色的框里。
