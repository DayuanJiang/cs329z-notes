一句话的结论

一个 LLM agent，就是把一个大语言模型放进一个循环里：想一步，通过工具做一步，看环境返回的结果，再想下一步。循环里下一步做什么由模型自己决定，这是 agent；由事先写好的代码决定，叫 workflow。把这样的系统搭出来已经不难，难的是让它可靠、安全，并且知道怎样评估它。

这里的 LLM 指大语言模型，prompt 指交给模型的输入文字，工具指模型可以调用的外部功能，环境指 agent 之外、它的动作作用在上面的那个世界。上下文指模型这一次调用能读到的全部文字，它的长度有上限。
