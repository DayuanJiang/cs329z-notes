一句话的结论

要把语言模型本身训练成更好的 agent，主要靠两种数据：拿来模仿的运行轨迹，和拿来练习的环境。它们有五种来源，越便宜、越容易做大的来源，离真实的人和真实的系统越远。数据里的漏洞和习惯，也会和能力一起被模型学进去。

这里的 agent，指能自己调用工具、分很多步去完成一个任务的语言模型系统。让它变强有两条路：模型不动，改它周围的 prompt、工具和检索；或者改模型本身。这一讲讲后一条，它发生在后训练（post-training）阶段，也就是模型在海量文字上预训练完之后，再用少量专门的数据继续训练的阶段。

下表把两种数据放在一起对照。表里有三个词先解释一下。

  • 沙盒（sandbox）是一个隔离的运行空间，agent 可以在里面随意操作，用完可以整个重置。
  • 验证器是判断任务做成没有的程序或评分办法。
  • 奖励（reward）是验证器在模型做完一次之后给的分数。

七个问题

这一讲分七个部分，每个部分回答一个问题。下表每行给出答案和一条依据。

表里有四个词先解释一下。

  • 基准测试（benchmark）是一套固定的题目，用来给模型打分。
  • 损失（loss）是模型的预测和实际内容之间的差距，训练的目标是让它变小。
  • 思维链（chain of thought）是模型在回答之前写下的推理过程。
  • 老师模型是产生运行轨迹的模型，它的轨迹拿去训练另一个模型，后者叫学生。

还有一个问题留给第 12 讲：有了这么多运行轨迹和环境，应该拿哪些来训练。

按部分阅读

第一部分为什么是数据

先说明改进 agent 有哪两条路，再给出数据最要紧的几类证据：各家不公开什么，为数据花多少钱，同一个基础模型换一份数据差多少。中间讲训练分哪三个阶段，以及网上的文字为什么不够。

 第二部分两种数据：运行轨迹和环境

这一部分讲运行轨迹里哪些部分算进训练，环境由哪三样东西组成，奖励有哪四种来源，以及两种数据各自怎么用来训练。最后看 DeepSeek 公开的各阶段数据量。

 第三部分数据从哪里来（上）：让人来做，从现成的材料里提取

先列出五种来源，再讲离真实最近的两种。请人演示的例子是 Mind2Web 和 OpenCUA，从现成的材料里提取的例子是 SWE-rebench、AgentTrek 和 VideoAgentTrek。

 第四部分数据从哪里来（中）：让模型合成轨迹、任务和环境

让模型合成轨迹有两条路：从一条指令出发把步骤写出来，或者先在环境里探索、事后再配上指令，例子是 Synatra、OS-Genesis 和 NNetNav。再进一步是成批造出任务和环境，例子是 SWE-smith、R2E-Gym 和 AgentScaler。

 第五部分数据从哪里来（下）：模拟的用户和模拟的环境

让语言模型扮演用户或者扮演整个环境，例子是 τ-bench、APIGen-MT 和 DreamGym。然后把五种来源放在一起比较。最后讲 data flywheel，也就是应用上线之后，拿真实使用中产生的记录来改进应用的循环。

 第六部分数据顺带教会了什么（上）：奖励的漏洞

这一部分讲奖励有漏洞时模型会学到什么。六个例子是从 git 历史里看到答案、骗过测试、藏起意图、认出自己在被评估、背题和讨好评分的人。第一个例子之后，接着讲怎样修环境把漏洞堵上。

 第七部分数据顺带教会了什么（下）：运行框架的格式和训练方式的副作用

先看同一个动作在三个运行框架里的写法，以及换框架之后成绩会怎样。然后讲监督微调和强化学习各自的问题，以及什么样的模型适合当老师。最后是整讲的小结。
