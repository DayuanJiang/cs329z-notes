先看结论

要把语言模型本身训练成更好的 agent，主要靠两种数据：拿来模仿的运行轨迹，和拿来练习的环境。它们有五种来源，越便宜、越容易做大的来源，离真实的人和真实的系统越远。环境里的漏洞、轨迹里的格式，也会和能力一起被模型学进去。

让 agent 变强有两条路。一条是模型的权重不动，改它周围的 prompt、放进 prompt 的示例、工具和检索。权重是模型里通过训练得到的那些数值，检索指让模型查外部资料的办法。另一条是改模型本身。这一讲讲后一条，它发生在后训练（post-training）阶段，也就是模型在海量文字上预训练完之后，再用少量专门的数据继续训练的阶段。

这一讲分七个部分，每个部分一页。五种来源是人工演示、从现成的材料里提取、合成运行轨迹、合成任务和环境、模拟的用户和环境，在第三到第五部分逐个讲。

上面说一种来源容易做大，指它的数据规模容易扩大，也就是能得到更多的任务、运行轨迹或单步样本。单步样本是只教下一步该做什么的一个例子。那句话说的是大致的走向：人工演示最贵、离真实最近，后四种的花费都低，第五部分的汇总表没有给这四种的花费排出高低。

下表把两种数据放在一起对照。表里有三个词先解释一下。

  • 沙盒（sandbox）是一个隔离的运行空间，agent 可以在里面随意操作，用完可以整个重置。
  • 验证器是判断任务做成没有的程序或评分办法。
  • 奖励（reward）是验证器在模型做完一次之后给的分数。

七个问题

这一讲的七个部分各回答一个问题。下表每行给出答案，以及依据或例子。

表里有几个词先解释一下。

  • 开放权重的模型是把权重公开出来、谁都可以下载的模型。
  • 基础模型是拿来继续训练的那个原始模型。微调是在已经训练好的模型上，用新的数据继续训练。
  • 基准测试（benchmark）是一套固定的题目，用来给模型打分。
  • token 是模型处理文字的最小单位，大致是一个词或半个词。
  • 损失（loss）是模型的预测和实际内容之间的差距，训练的目标是让它变小。
  • 思维链（chain of thought）是模型在回答之前写下的思考过程。
  • 老师模型是产生运行轨迹的模型，它的轨迹拿去训练另一个模型，后者叫学生。
  • 标注者是受雇来做任务的人。
  • 指令是交给 agent 的那句任务描述。

还有一个问题留给第 12 讲：有了这么多运行轨迹和环境，应该拿哪些来训练。

按部分阅读

第一部分为什么是数据

先说明改进 agent 有哪两条路，再用三类证据说明数据为什么要紧：各家公开什么、不公开什么，市场上为数据花多少钱，同一个基础模型换一份数据差多少。中间讲训练分哪三个阶段，以及网上的文字为什么不够。

 第二部分两种数据：运行轨迹和环境

这一部分讲运行轨迹里哪些部分算进训练，环境由哪三样东西组成，奖励有哪四种来源，以及两种数据各自怎么用来训练。最后看 DeepSeek 公开的各阶段数据量。

 第三部分数据从哪里来（上）：让人来做，从现成的材料里提取

先列出五种来源，再讲离真实最近的两种。人工演示的例子是 Mind2Web 和 OpenCUA，前者录的是网页上的操作，后者录的是整个桌面上的操作。从现成的材料里提取的例子有三个：SWE-rebench 用 GitHub 的代码历史，AgentTrek 用网上的教程，VideoAgentTrek 用录屏视频。

 第四部分数据从哪里来（中）：让模型合成轨迹、任务和环境

合成运行轨迹有两条路。一条是先有指令，例子是 Synatra，它让语言模型把步骤写出来，不执行。另一条是先有交互，例子是 OS-Genesis 和 NNetNav，它们先在应用或网站里探索，再根据探索写出指令。再进一步是合成任务和环境，也就是成批造出沙盒、任务和验证器：SWE-smith 和 R2E-Gym 造的是编程任务，AgentScaler 造的是工具调用的环境。

 第五部分数据从哪里来（下）：模拟的用户和模拟的环境

让语言模型扮演用户或者扮演整个环境。τ-bench 和 APIGen-MT 模拟的是用户，DreamGym 模拟的是环境。然后把五种来源放在一起比较。最后讲 data flywheel，也就是应用上线之后，拿真实使用中产生的记录来改进应用的循环。

 第六部分数据顺带教会了什么（上）：奖励的漏洞

这一部分讲奖励有漏洞时模型会学到什么。六个例子是从 git 历史里看到答案、让测试不经检查就通过、被监控之后把意图藏起来、认出自己在被评估、背下基准测试的题和答案、学会让评分的人觉得对。第一个例子之后，接着讲怎样修环境把漏洞堵上。

 第七部分数据顺带教会了什么（下）：运行框架的格式和训练方式的副作用

先看同一个动作在三个运行框架里的写法，以及换框架之后成绩会怎样。然后讲监督微调和强化学习各自的问题，以及最强的模型是不是最好的老师。最后是整讲的小结。
