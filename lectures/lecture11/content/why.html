先看结论

  • agent 是能自己调用工具、分很多步去完成任务的语言模型系统。让它变强有两条路。一条是模型的权重（weights，模型里通过训练得到的那些数值，模型的行为由它们决定）不动，改它周围的东西：prompt、放进 prompt 的示例、工具、检索。检索指让模型查外部资料的办法。另一条是改模型本身的权重，这条路上最主要的手段是数据。这一讲讲第二条。
  • 开放权重的模型是把权重公开出来、谁都可以下载的模型。这类模型通常把结构和训练过程写得很细，对训练数据却几乎不提。从各家公开什么、不公开什么来看，数据是各家最不愿意公开的部分。由此可以推断，数据很可能也是各家模型之间最主要的差别。这一步是推断，依据和推断的过程见正文。
  • 语言模型的训练分三个阶段，每个阶段用的数据不同。第一个阶段是预训练，也就是模型在海量文字上做的第一段训练，用的是网上的文字。第二个阶段是监督微调和 RLHF，用的是对话：监督微调拿现成的示范继续训练模型，RLHF 按人对回答的评价来更新模型。第三个阶段是强化学习，让模型在环境里自己去做、按结果的好坏来更新，用的是环境。
  • agent 数据指后两样：对话和环境。环境是练习的地方，模型在里面自己做，做完有人或程序告诉它做得对不对。放到 agent 任务上，对话就是运行轨迹，也就是一次解题过程的完整记录。
  • 网上的文字只展示别人写下来的结果。agent 要学的是自己动手：发出一个动作，看到结果，再决定下一步。这样的过程在网上很少有现成的记录，所以需要环境：环境让模型自己去做，每一步都得到反馈。
  • 有公开的对照实验表明后训练数据的影响很大。后训练（post-training）指预训练之后再用少量专门的数据继续训练的阶段，监督微调和强化学习都属于它。实验用同一个基础模型（拿来继续训练的那个原始模型，这里是开放权重的 Qwen3-32B），只做监督微调，换用三份不同的公开数据集。训练出的三个模型在七个 agent 基准测试（benchmark，一套固定的题目，用来给模型打分）上的平均准确率分别是 28.1%、40.9% 和 44.8%，不微调时是 22.8%。三份数据的条数不同，依次是 2.5 万、26.4 万和 10 万条，所以这三个数里也有数据多少的影响。条数相同时的比较见正文的图，数据集之间的差别仍然在。

为什么说数据是模型之间最主要的差别

「数据是模型之间最主要的差别」这个看法有三条依据，下表逐条列出。这些依据分成两类。一类是直接的说法：第一条说模型的行为由数据决定，第二条说训练语言模型时最要紧的是把数据做好。另一类是旁证，也就是第二条给出的理由和第三条：开放权重的模型把结构和训练过程都公开了，对数据几乎不提。

表里第一行有三个训练模型时用的词，先解释一下。

  • 收敛（converge）指训练到后来，模型的结果不再有明显变化，停在了某一个结果上。
  • 超参数（hyperparameter）是训练开始前由人设定的数值，比如每次更新权重的幅度。
  • 优化器（optimizer）是训练时用来一步一步更新权重的算法。

从「不公开数据」到「数据是最主要的差别」，中间还有一步，三份材料都没有写出来。这一步可以这样推：CS336 给出的第一个保密原因是竞争。结构和训练过程公开之后，别人可以照着做，各家仍然不公开数据，可以理解为它们把数据看作和别家拉开差距的地方。第二个保密原因是版权责任，它和数据重不重要无关，所以「不公开数据」这件事只算旁证。

各家不公开数据的情况到 2026 年没有变。Moonshot AI 在 2026 年 6 月把 Kimi K3 这个模型的权重放到了 Hugging Face 上，Hugging Face 是一个公开存放模型和数据集的网站。模型页面逐项列出了模型结构的各项规格，没有提到训练数据。2026 年 6 月的论文《Data Recipes for Agentic Models》（OpenThoughts-Agent 项目）在引言里举了另一个例子：DeepSeek V4 的权重是开放的，随这个模型一起发布的论文有 50 多页讲结构和训练过程，讲训练数据的只有两段。

i
Betker 的观察针对的是什么模型。他文章里举的例子都是图像生成模型，一共两组。第一组比的是模型的结构：卷积网络和 ViT（vision transformer）是两种处理图像的网络结构，用它们各搭一个图像生成模型，模型足够大时会产生同样的图像。第二组比的是生成的办法：自回归采样把图像一小块接一小块地生成出来，扩散采样从一张全是噪声的图出发、一步一步去掉噪声，这两种办法也会产生同样的图像。把这个结论用到语言模型和 agent 上是一种推广。表里的第二条依据说的就是语言模型，它的结论相同：最要紧的是数据。

训练的三个阶段，agent 数据在哪一段

训练一个语言模型，先后要经过三个阶段：第一个阶段是预训练，第二个阶段是监督微调和 RLHF，第三个阶段是强化学习。这三个阶段是按用的数据来分的，每个阶段需要的数据不一样。

RLHF 是 reinforcement learning from human feedback 的缩写，指用人对回答的评价当奖励来做强化学习。它的训练方法是强化学习，用的数据仍然是对话，所以和监督微调排在同一个阶段。第三个阶段说的强化学习，指在环境里做的强化学习。

训练的阶段还有别的分法。第二部分用到的一种是按先后分成预训练、中期训练和后训练三段。这里的第二、第三个阶段，在那种分法里都属于后训练。

行业最看重哪种数据，是按这三个阶段的顺序依次变过来的。Andrej Karpathy 在 2025 年 8 月的一篇帖子里把这个变化说成三个时期，他的原词是 era：预训练的时期要紧的是网上的文字，监督微调的时期要紧的是对话，现在强化学习的时期要紧的是环境。阶段说的是一个模型训练的先后步骤，时期说的是行业发展的先后，每个时期最要紧的数据，就是对应的那个阶段用的数据。

下面的图和表按阶段来排，表里「数据怎么来」一列用的是他帖子里的说法。

{{fig 8 | 左：三个训练阶段和各自用的数据。右：Andrej Karpathy 2025 年 8 月 27 日发在 X 上的帖子，高亮的一句说的是环境让模型有机会真正去交互。}}

agent 数据通常指后两样：对话和环境。对话是示范，告诉模型该怎么做。环境是练习的地方，模型在里面自己做，做完有人或程序告诉它做得对不对。

放到 agent 任务上，对话就是运行轨迹（trajectory）：一次解题过程的完整记录。它在格式上仍是一段对话，只是轮流出现的除了任务和 agent 的回答，还有 agent 每一步的动作和工具返回的结果。第二部分有一条完整的例子。

Karpathy 在这篇帖子里说，前两种数据都不会消失，但在现在这个强化学习的时期，重要的是环境。环境和前两种数据的区别是：它给模型一个真正去交互的机会，可以采取动作、看到结果。他接着说，有了环境，模型就有希望比 statistical expert imitation 做得好很多。这个词可以理解为照着专家的示范去模仿。预训练和监督微调都是让模型照着人写下的内容去模仿。

+
同一篇帖子的后半段。Karpathy 接着说，他长期看好环境，也看好让模型像 agent 那样自己动手去交互，但对强化学习这个具体方法并不看好。他给了两个理由。一个是奖励函数很不可靠，奖励函数指算出奖励的那套规则，他没有展开说哪里不可靠。另一个是他认为人在解决智力问题时用的不是强化学习。帖子里还提到，OpenAI 最早的项目 Gym 就是想把大量环境收进同一套接口，只是那时的环境是倒立摆、Atari 游戏这类简单的控制任务。出处：Karpathy 的帖子。

同一个基础模型，换一份数据会差多少

公开的对照实验里，最直接的一组来自 Raoof 等人 2026 年 6 月的论文《Data Recipes for Agentic Models》。这个项目叫 OpenThoughts-Agent，简称 OT-Agent。

下面的图里有几个名字，先解释一下。

  • Qwen3 是阿里巴巴的 Qwen 团队公开权重的一个语言模型系列。Qwen3-32B 和 Qwen3-8B 是其中一大一小两个模型，名字里的 B 指十亿，32B 就是大约 320 亿个权重。实验拿它们当基础模型。
  • SWE-bench Verified 是一个基准测试，让模型修复真实代码仓库里的问题，共 500 道经过人工筛选的题。
  • Terminal-Bench 2.0 是另一个基准测试，让模型在命令行（终端）里完成技术任务。
  • SWE-agent 和 Terminus-2 是两个运行框架。运行框架（harness）是包在模型外面、给它工具并管理多轮对话的程序。模型要放进一个运行框架里才能做题，所以每个成绩都是在某一个框架里测出来的。

图上比较的是三份公开的训练数据，每一份都是一批运行轨迹。

  • OT-Agent 的数据是这篇论文自己整理出来的，目标是让模型在多个 agent 基准测试上都变好。
  • Nemotron-Terminal-Corpus 是 NVIDIA 公开的一份数据，里面是在命令行里完成任务的运行轨迹。
  • SERA 是 Allen Institute for AI 的一项工作。这个名字指一套训练写代码 agent 的办法，也指用这套办法训练出的模型，比如下面表里的 SERA-32B。它公开的训练数据是让一个模型在 SWE-agent 里修改代码仓库得到的运行轨迹，下面叫 SERA 的数据。

!
这张图比的是三份不同的数据集。几条线是三份不同来源的数据集（OT-Agent、Nemotron-Terminal-Corpus、SERA），在每个横坐标上各取同样条数来训练，图上比的是这三份数据集之间的差别。横轴是训练集大小，容易让人以为图上比的是「同样多的轨迹，从同一份数据里挑出最有效的子集效果更好」，图上没有这样的比较。怎样从一份数据里挑出该用的部分，是论文里另外一百多个对照实验研究的问题，也是第 12 讲的主题。

紫线和别的线之间还多一处不同：运行框架。OT-Agent 和 Nemotron-Terminal-Corpus 的数据都是用 Terminus-2 产生的，红线、蓝线、橙线和青线对应的模型也都在 Terminus-2 里测。SERA 的数据是用 SWE-agent 产生的，所以用它训练的模型在 SWE-agent 和 Terminus-2 里各测了一次，左边和中间的小图上各有两条紫线。紫线和别的线之间的差距里，也就有运行框架的影响。

运行框架的影响有多大，可以比较这两条紫线。同一个模型，在产生训练数据的那个框架里，SWE-bench Verified 的成绩高出很多：从图上读，数据量最大时在 SWE-agent 里大约是 52%，在 Terminus-2 里大约是 23%。紫线的数据量最大是 4.7 万条，因为 SERA 公开的训练数据最多有这么多。第七部分专门讲这件事。

OT-Agent 的线没有在每张小图、每个数据量上都领先。左边那张图里，数据量较小时，在 SWE-agent 里测的那条 SERA 的线明显更高。中间那张图里，3.16 万条附近蓝线略高于红线。论文给这张图写的图注，说的是 OT-Agent 在数据量大时领先。论文摘要说，在让各份数据用同样多的算力来训练的比较里（原文是 compute-controlled comparisons），他们的训练数据在每一个训练集大小上都超过其他开放数据集，这句话大致对应右边「七个基准测试的平均」那张小图。
