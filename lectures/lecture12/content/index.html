一句话的结论

训练 agent 用的任务和运行轨迹，现在造起来很便宜。要花力气的是决定留下哪些。

任务要先确认本身是对的，再留下对模型不太容易也不太难的。轨迹要看它是怎么通过测试的，没通过的也有办法用。

从这一讲的几个实验可以归纳出：候选数据有限、质量参差时，挑选最有价值。数据本来就都合格、还能再加时，数据量和多样性更重要。

这里的 agent，指能自己调用工具、分很多步去完成一个任务的语言模型系统。运行轨迹（trajectory）是 agent 一次运行里每一步的动作和看到的结果的完整记录。第 11 讲讲的是这些数据从哪里来，这一讲讲造出来之后怎么挑。

要挑的东西有三样，下表每样占一列。表里的 LEGO-RL 和 Orchard 是论文的名字，各自在「在哪一页」那一行指向的页面里介绍。基准测试（benchmark）指一组题目加一个打分的办法，用来比较不同的模型。
